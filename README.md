# Player Detection & Performance Analysis 

### About this project

VisionXI is a Computer Vision project that detects and tracks football players from match videos.
The system is designed to help coaches and football clubs in Suriname get more insight into player performance and movement.

### Doelstellingen

- Spelers detecteren
- Spelers volgen in video's
- Teams classificeren
- Spelerbewegingen analyseren
- Prestatiegegevens verzamelen

### Computer Vision task
- Object Detection
- Object Tracking
- Classification
